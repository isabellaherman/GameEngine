GameEngine · Bend — como compilar e abrir
=========================================

Todos os comandos rodam dentro desta pasta:
  cd ~/Documents/HOC/GameEngine

ABRIR O APP (compila se precisar e abre a janela, GPU/Metal)
  make run

COMPILAR (build) SEM ABRIR
  make
  -> gera build/esfera e build/esfera.gpu (os dois precisam ficar juntos)

ABRIR UM BUILD JÁ FEITO
  ./build/esfera

OUTROS
  make cpu      abre a mesma cena rodando na CPU (comparação)
  make test     roda os testes na GPU e na CPU
  make check    só verifica os arquivos .bend, sem compilar
  make clean    apaga a pasta build/

SEM MAKE (equivalente)
  mkdir -p build
  bend main.bend -o build/esfera
  ./build/esfera

NO VS CODE
  Cmd+Shift+B           compila
  Terminal > Run Task   compilar / abrir (GPU) / abrir (CPU) / testar

CONTROLES
  PLAY/PAUSE ou Espaço  retomar/pausar a órbita da câmera
  RESET ou R            voltar ao ângulo inicial
  Clique em SCENE       seleciona o objeto; o INSPECTOR mostra os valores dele
  Esc ou fechar         sair

REQUISITOS
  - Bend no PATH (bend version)
  - Xcode/Clang + compilador Metal
  - Bend-UI em ../Bend-UI (a UI importa os tokens de lá)
